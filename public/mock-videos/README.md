# Videos de demo (modo mock)

Los ejercicios del seed apuntan a `seed/<clave>.mp4`. Si ponés acá un archivo con ese nombre,
el modo mock lo reproduce. Si no está, se ve el placeholder del diseño.

Claves: flexores, goblet, rdl, bulgara, nordic, hip-thrust, copenhagen, pallof, talones,
unipodal-banco, saltos-laterales, plancha, remo-banda, flexiones.

Recomendado: .mp4 (H.264), vertical 9:16, 720p, menos de 60 s y pocos MB.
